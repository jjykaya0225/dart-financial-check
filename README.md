# DART 재무제표 정합성 자동 검증

OpenDART API로 상장사 연결재무제표를 수집하고, 감사에서 기본으로 확인하는 **재무제표 간 정합성**을 Python으로 자동 점검한 프로젝트입니다.

- **대상**: 삼성전자 · SK하이닉스 · LG전자, 2024·2025 사업연도 연결재무제표
- **사용 도구**: Python (requests, pandas), OpenDART API

---

## 결과 요약

| 항목 | 결과 |
|---|---|
| 정합성 검증 | 24건 중 **통과 20건 · 불일치 0건 · 확인불가 4건** |
| 확인불가 원인 | LG전자·SK하이닉스의 현금흐름표 본문에 당기순이익 행이 없어, 본문만으로는 순이익 일치를 검증할 수 없음 |
| 정제 중 발견 | 같은 이름의 계정 중복, 연도별로 바뀐 계정명 → 계정명 대신 XBRL 표준 계정 ID로 계정을 식별 |
| 이상 변동 | 전기 대비 ±30% 이상 변동 계정 자동 추출 (예: SK하이닉스 2024 당기법인세부채 약 70배) |

공시된 재무제표는 외부감사를 받은 자료라 불일치가 없는 것이 정상입니다. 이 프로젝트의 목적은 오류를 찾는 것보다, **정합성을 자동으로 점검하는 틀**을 만드는 데 있습니다.

## 검증 항목

| 검증 | 내용 |
|---|---|
| ① 재무상태표 항등식 | 자산총계 = 부채총계 + 자본총계 |
| ② 순이익 일치 | 손익계산서 당기순이익 = 현금흐름표 당기순이익 |
| ③ 현금 일치 | 현금흐름표 기말 현금 = 재무상태표 현금및현금성자산 |
| ④ 현금 증감 | 기초 현금 + 현금 증감 = 기말 현금 |
| ⑤ 이상 변동 | 재무상태표 계정 중 전기 대비 ±30% 이상 변동 (자산총계의 1% 이상 계정만) |

## 처리 과정

1. **기업 고유번호 조회**: 전체 기업 목록(XML)에서 종목코드로 DART 고유번호를 찾습니다.
2. **재무제표 수집**: `fnlttSinglAcntAll` API로 회사·연도별 전체 재무제표를 받습니다.
3. **정제**: 문자열 금액을 숫자로 변환하고, 회사마다 다른 계정명을 XBRL 표준 계정 ID로 맞춥니다.
4. **검증**: 위 ①~④ 규칙을 회사·연도별로 자동 점검합니다.
5. **이상 변동 탐지**: 변동이 큰 계정을 추출해 감사에서 우선 살펴볼 대상을 고릅니다.

자세한 해석은 노트북의 **6. 해석** 섹션에 있습니다.

## 실행 방법

1. [OpenDART](https://opendart.fss.or.kr)에서 인증키를 발급받습니다.
2. 노트북과 같은 폴더에 `dart_key.txt`를 만들고 인증키를 한 줄로 저장합니다. (`.gitignore`에 포함되어 저장소에는 올라가지 않습니다.)
3. `pip install requests pandas` 후 노트북을 처음부터 실행합니다.

## 한계와 개선 방향

- 부호가 바뀌는 계정(예: 음수 → 양수)은 변동률이 왜곡되므로 따로 분리해야 합니다.
- 현금흐름표 순이익 검증은 주석 데이터까지 수집하면 모든 회사에 적용할 수 있습니다.
- 이상 변동의 실제 원인은 사업보고서 주석으로 확인해야 합니다.
